Task 0.4 — Create Django Project

Move into backend:

cd backend

Install Django:

pip install django

Create project:

django-admin startproject config .

Result:

backend/

├── config/
│   ├── settings.py
│   ├── urls.py
│   ├── asgi.py
│   └── wsgi.py

Task 0.5 — Convert Settings to Enterprise Structure

Current:

config/settings.py

Change to:

config/settings/

├── __init__.py
├── base.py
├── development.py
├── production.py
└── testing.py

Why?

Because SaaS environments are different:

Development:

DEBUG=True
SQLite/PostgreSQL
local email

Production:

DEBUG=False
PostgreSQL
S3
Redis
Celery

Testing:

isolated database
